# Instalación de VirtualBox - Guía 8

## Propósito

Este documento describe los pasos y evidencias para la instalación y configuración de VirtualBox como parte de la Guía 8 de Sistemas Operativos.

## Evidencias disponibles

Los siguientes archivos fueron identificados y organizados en el repositorio:
- `diagnostico_virtualbox.ps1` - Script de diagnóstico de VirtualBox
- `diagnostico_virtualbox.txt` - Reporte de diagnóstico en texto
- `prueba_virtualbox_memory.ps1` - Prueba de configuración de memoria
- `prueba_virtualbox_memory.txt` - Resultados de prueba de memoria
- `prueba_virtualbox_partial.txt` - Prueba parcial de VirtualBox
- `verificacion_virtualbox.ps1` - Script de verificación
- `verificacion_virtualbox.txt` - Resultados de verificación

## Fases identificadas

Según el análisis de los archivos diagnósticos, el proceso sigue estas fases:
1. **Fase 3**: Configuración inicial y diagnóstico del entorno VirtualBox
2. **Fase 4**: Pruebas de rendimiento y verificación de configuración

**Nota**: Los archivos de la Fase 1 y Fase 2 no fueron encontrados con ese nombre específico en el repositorio, aunque se identificaron componentes relacionados.
